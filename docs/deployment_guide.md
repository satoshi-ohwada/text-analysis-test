# イントラネット（社内ネットワーク）配信・配置ガイド

あまり使われていない常時起動のWindows PCを「簡易サーバー」として利用し、社内の他のPCからIPアドレスでアクセスしてワードクラウドアプリを使えるようにするための方法です。

---

## 必要な準備（共通）

どのサーバーソフトウェアを使う場合でも、**サーバーにするWindows PCのIPアドレス**を事前に確認し、固定しておくか把握してください。
また、外部からアクセスさせるため、**Windows Defender ファイアウォールでポート（例: 8000）の通信許可を設定**する必要があります。

### ファイアウォールの許可設定（Windows）
1. スタートメニューで「セキュリティが強化された Windows Defender ファイアウォール」を検索して開きます。
2. 左メニューの「受信の規則」をクリックし、右メニューの「新しい規則...」をクリックします。
3. 規則の種類で「ポート」を選び、「次へ」を押します。
4. 「特定のローカルポート」に `8000` を入力し、「次へ」を押します。
5. 「接続を許可する」を選び、「次へ」を押します。
6. プロファイル（ドメイン・プライベート・パブリック）で、社内ネットワークである「ドメイン」や「プライベート」にチェックを入れ（パブリックはセキュリティのため非推奨）、「次へ」を押します。
7. 名前を「WordCloud Server Port 8000」などと入力し、「完了」を押します。

## おすすめのサーバー方法

### 方法1: 拡張版 PowerShell サーバー（追加インストール不要）
現在作成した `start_server.ps1` を少し修正し、他のPCからも接続を受け付けるようにします。

*   **動作手順**:
    1. 管理者としてコマンドプロンプトやPowerShellを開きます（IPバインド権限のため管理者権限が必要になります）。
    2. `start_server.ps1` のアドレス登録箇所を以下のように書き換えて起動します。
       `$listener.Prefixes.Add("http://*:8000/")`
    3. 他のPCから `http://[サーバーのIPアドレス]:8000/` でアクセスします。

### 方法2: HFS (HTTP File Server) 【GUI付き・最もおすすめ】
Windows用のフリーのWebサーバーソフトで、1つの実行ファイル（exe）だけで動作します。視覚的に接続者数や帯域がわかるため、管理が最も楽です。

*   **公式サイト**: [https://www.rejetto.com/hfs/](https://www.rejetto.com/hfs/)
*   **特徴**:
    *   インストール不要（exeを実行するだけ）。
    *   画面上でアクセスしてきた人のログ（IPアドレスや時間）がリアルタイムに表示されます。
    *   公開するフォルダ（`wordcloud_app`）を、HFSのウィンドウにドラッグ＆ドロップするだけで即座に公開できます。

### 方法3: Pythonを使う（インストール済みの場合）
サーバーPCにPythonがインストールされているなら、コマンドプロンプトで公開したいフォルダに移動し、以下の一行を実行するだけで外部公開サーバーになります。

```cmd
cd C:\path\to\wordcloud_app
python -m http.server 8000 --bind 0.0.0.0
```
*   `--bind 0.0.0.0` と指定することで、外部からのアクセスを受け付けるようになります（指定しないとlocalhost専用になります）。
*   Kuromojiの辞書読み込みエラー（二重圧縮解凍問題）が発生しないため、動作が非常に安定しています。

### 方法4: Windows標準機能 IIS (Internet Information Services) 【常時稼働向け】
Windowsの標準機能として組み込まれているプロ仕様のWebサーバー機能です。

*   **特徴**:
    *   Windowsのバックグラウンドサービスとして動作するため、**PCを再起動した際もユーザーがログインすることなく、自動で裏でサーバーが再起動します**。
    *   追加のダウンロードは一切不要で、Windowsの「機能の有効化または無効化」から「インターネット インフォメーション サービス」をONにするだけで有効化できます。
*   **注意点**:
    *   標準設定のIISでは、GZIPファイル（Kuromojiの辞書）がダウンロードされた際に自動でブラウザ側が解凍してしまう二重圧縮問題が起きる場合があります。その場合はIISのMIMEマップ設定で `.gzip` を `application/x-gzip` または `application/octet-stream` に設定してください。
